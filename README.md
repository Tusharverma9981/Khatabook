# 📒 Hisaab - Simple File-Based Note Manager

Hisaab is a lightweight web app that allows you to create, view, edit, and delete `.txt` files, acting as a simple note-taking or record-keeping tool. Each note is stored as a plain text file inside a `hisaab/` directory.

## 🚀 Features

- 📄 Create new notes
- 📂 List all existing notes
- ✏️ Edit existing notes
- 🗑️ Delete notes
- 📖 View the content of any note

## 🛠️ Tech Stack

- Node.js
- Express.js
- EJS (Embedded JavaScript Templates)
- HTML/CSS (with optional static files in `/public`)
